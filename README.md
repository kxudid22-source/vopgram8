# Vopgram

Полноценный мессенджер с анонимными номерами +888, верификацией в стиле Telegram, чатами, профилем и магазином подарков.

## Локальный запуск

```bash
cp .env.example .env
# при необходимости укажите BOT_TOKEN от @BotFather
npm install
npm start
```

Откройте http://localhost:3000

Демо-номер для теста: `+888 777 77 77`, код `123456`.

## Деплой на бесплатный сервер (Render)

1. Зарегистрируйтесь на https://render.com
2. New → Web Service → подключите репозиторий (или загрузите код)
3. Render сам подхватит `render.yaml` (Docker).
4. В Environment добавьте `BOT_TOKEN` (от @BotFather), если нужен бот.
5. Нажмите Deploy. Бесплатный тариф засыпает при бездействии — это нормально для демо.

## Бот для выдачи номеров

1. Создайте бота через @BotFather, получите токен.
2. Положите токен в `.env` как `BOT_TOKEN`.
3. Пользователь пишет боту /start — бот выдаёт анонимный номер +888 и код подтверждения.
4. Код вводится в приложении.

## Структура

- `server.js` — Express + Socket.io + REST API
- `db.js` — SQLite (better-sqlite3)
- `public/` — фронтенд (SPA)
- `Dockerfile`, `render.yaml` — деплой
